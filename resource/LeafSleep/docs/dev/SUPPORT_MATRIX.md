# LeafSleep (OnePlayerSleep) Support Matrix

Canonical platform and Minecraft version compatibility matrix for **LeafSleep (OnePlayerSleep)**.

---

## Minecraft Version & Platform Compatibility (1.20.x – 26.3)

**LeafSleep (`OnePlayerSleep`) supports Minecraft `1.20.x`, `1.21.x` (`1.21.1`–`1.21.11`), `26.1`, `26.2`, and `26.3`** across Paper, Folia, Spigot, Purpur, Fabric, NeoForge, and Velocity/Redis multi-server shards.

| Platform / Loader | Supported Minecraft Versions | Java Requirement | Capabilities | Status |
|---|---|---|---|---|
| **Paper / Purpur / Pufferfish** | `1.20.x`, `1.21.x`, `26.1`, `26.2`, `26.3` | Java 17 / 21+ | Quorum sleep (`defaultQuorumPolicy`), sleep animations, Phantom control, cross-server `sharding.transport` | **Tier-1 Supported** |
| **Folia** | `1.20.x`, `1.21.x`, `26.1`, `26.2`, `26.3` | Java 21+ | Regionized-thread safe bed/time progression (`F-001..F-003`) | **Tier-1 Supported** |
| **Spigot / Fabric / NeoForge** | `1.20.x`, `1.21.x`, `26.1`, `26.2`, `26.3` | Java 17 / 21+ | `/sleep`, `/ops test`, `/ops version`, quorum & weather skip | **Supported** |
